## What I've built

- **[PaddyMonitor](https://github.com/wesleyGitHub123/PaddyMonitor)**: a handheld probe that reads the moisture of paddy and flags spoilage risk. A Random Forest trained on 196 readings caught 95% of high-risk grain on containers it had not seen. The README states the limits: the sensor can't tell dry grain from safe grain, and the moisture levels were calculated, not measured with a reference meter. Demo video in the README.
- **[truing-bench](https://github.com/wesleyGitHub123/truing-bench)**: firmware and test rig for a bicycle-wheel truing machine. It's a team capstone and I'm the technical lead. A partially working prototype: 326 host tests pass and the laser-indexed roller works, but solenoid strikes don't give a usable frequency yet. The README says what works and what doesn't.
- **[cisco-pt-mcp](https://github.com/wesleyGitHub123/cisco-pt-mcp)**: my fork of a Packet Tracer MCP server, extended from 11 to 151 device models. I used it with an AI agent to build a 116-device clinic network from a floor plan.
