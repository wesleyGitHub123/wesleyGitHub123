# Hi, I'm Wesley

CpE student in Metro Manila, graduating in 2027. I build things on the ESP32-S3, and I like seeing how much I can get out of cheap sensors with small machine-learning models. I use AI coding tools and direct the work: I design the systems, wire the hardware and test it.

## Things I've built

- **[PaddyMonitor](https://github.com/wesleyGitHub123/PaddyMonitor)**: a handheld probe that reads paddy moisture and flags grain that's at risk of spoiling. It runs a Random Forest trained on 196 readings, and it caught 95% of the high-risk grain on containers it hadn't seen. The README is upfront about the limits: the sensor can't tell dry grain from safe grain, and the moisture levels were calculated from the water I added, not checked against a reference meter. There's a demo video too.
- **[truing-bench](https://github.com/wesleyGitHub123/truing-bench)**: firmware and test rig for a bicycle-wheel truing machine. It's a team capstone and I'm the technical lead. It's a partial prototype: 326 tests pass and the laser-indexed roller works, but the solenoid strikes still don't give a usable frequency. The README says what works and what doesn't.
- **[cisco-pt-mcp](https://github.com/wesleyGitHub123/cisco-pt-mcp)**: my fork of a Packet Tracer MCP server. I took it from 11 device models to 151 and used it with an AI agent to build a 116-device clinic network from a floor plan.
